# FrFndr

> **Fr**ame **F**in**d**e**r** — Minecraft 展示框物品搜索定位模组

按物品名高亮附近装着该物品的**物品展示框**，支持连线指向与方框高亮两种样式。纯客户端模组，服务端无需安装。

---

## 功能

### 🔍 物品搜索

输入物品名（支持三种写法），自动扫描附近所有展示框并高亮匹配项：

| 匹配层       | 示例输入                  | 命中                  |
| --------- | --------------------- | ------------------- |
| 注册名       | `diamond`             | `minecraft:diamond` |
| 中文显示名     | `钻石`                  | 钻石、钻石块、钻石剑…         |
| 英文显示名     | `sword`               | 各类剑                 |
| **附魔书内容** | `灵魂疾行` / `soul_speed` | 附魔书（读存储附魔组件）        |

### 📌 两种高亮样式（`/sou style` 随时切换）

| 样式     | 效果                                       |
| ------ | ---------------------------------------- |
| **连线** | 从准星到每个展示框中心画一条发光连线，颜色随距离渐变（近绿 → 远橙），穿墙可见 |
| **方框** | 展示框包围盒的半透明填充 + 白色描边，穿墙可见                 |

### 🖥 GUI 搜索界面（默认 `K` 键）

- 输入框**实时匹配预览**：边打字边显示命中的物品图标（从创造物品栏全物品表过滤）
- 命中的展示框列表（滚轮翻页，可看全部）：名称 · 距离 · 坐标
- 回车直接设为搜索目标

### ⚙️ 其他

- 扫描半径 16~256 格可调（`/sou radius N`），**持久化**到配置文件
- 搜索目标**持久化**（重启游戏不丢）
- 集成 ModMenu（设置按钮直接打开搜索界面）
- 中文/英文语言文件

---

## 命令

```
/sou <物品>      搜索（注册名/中文/英文/附魔书，重复输入取消）
/sou off         清除全部搜索目标
/sou list        查看当前目标
/sou radius N    设置扫描半径（16~256，持久化）
/sou style       连线 / 方框切换（持久化）
K                打开 GUI 搜索界面（可在按键设置中修改）
```

## 安装

1. 安装 [Fabric Loader](https://fabricmc.net/use/)（0.19.5+）
2. 安装 [Fabric API](https://modrinth.com/mod/fabric-api)
3. 把 `frfndr-*.jar` 放进 `.minecraft/mods/`
4. 启动游戏，`/sou <物品名>` 开始搜索，或按 `K` 打开 GUI

## 使用场景

- **储藏室找东西**：整面墙的展示框里快速定位某类物品
- **仓库管理**：确认某个展示框里放的是什么
- **附魔书分类**：按附魔名找特定的附魔书展示框
- **BOT自动分类**：搜索能工智人分类物品给箱子展示框添加的物品

## 技术说明

- 纯客户端实现：展示框内容由服务端同步给客户端，无需服务端配合
- 扫描每 0.25 秒自动刷新，后台执行不卡顿
- 连线/方框使用自建渲染管线（26.3 新渲染系统 `RenderSetup` + 独立 `RenderPass`），参考了 [Wurst 7](https://github.com/Wurst-Imperium/Wurst7)（GPL-3.0）的渲染架构
- 26.3 顶点格式要求 position + color + normal + lineWidth 四要素齐备，并包含 ESP 式的"穿屏补顶点"修复

## 已知限制

- 仅匹配展示框**正面摆放的物品**（这是展示框的唯一形态）
- 远程服务器上只能看到**已加载区块**内的展示框
- 26.3 渲染系统在 Iris 等光影 mod 下理论兼容（管线独立于光影阴影通道），未在全部光影下测试
